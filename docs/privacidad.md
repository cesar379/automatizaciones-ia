# Privacidad

## Sí se sube

Código, flujos sin credenciales, esquemas, plantillas, documentación y casos de prueba anonimizados o ficticios.

## No se sube

- Facturas, tickets, extractos, contratos ni resultados reales.
- NIF, IBAN, nombres de proveedores o clientes ni importes reales.
- Claves de API, contraseñas ni tokens.
- Configuración real de empresas: `clientes/` solo versiona la plantilla.

Los datos reales permanecen en los sistemas de cada empresa. El historial de Git conserva lo que se sube: si se sube algo sensible por error, hay que revocar los secretos afectados y limpiar el historial.
